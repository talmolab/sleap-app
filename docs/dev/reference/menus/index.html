Connect and Start Tutorial¶

Buttons in the menu bar, not menus.

  • Connect opens the same Connect window as Predict ▸ Connect (Remote Training / Inference)….
  • Start Tutorial runs the guided walkthrough of the labeling → training → correction → inference loop. It builds its own project from a sample video. If you already have a project open, it offers to run in a new window so your project is left alone. In the desktop app it starts by checking that uv and sleap-nn are installed, and warns you if training will run on the CPU. In the browser it explains that models can't be trained there, and ends after labeling.
