This is a SLEAP web-based frontend app.

It is deployed to a static page endpoint (app.sleap.ai), as well as compiled to a Tauri-based desktop app. Many code paths vary depending on the runtime environment, especially for I/O.

# Development
- Node 22 (see `.nvmrc`).
- `main` is protected. You must work on branches, PR, and squash merge.
- Path alias: `@/` → `./src/` in imports.
- `src/components/ui/` is auto-generated by shadcn/ui — don't hand-edit. Add new components with `npx shadcn@latest add <component>`.

## sleap-io.js
This app makes extensive use of `sleap-io.js` for I/O, data model, SLP file handling, video decoding, playback, HDF5 ops.
- Source: https://github.com/talmolab/sleap-io.js
- Docs: https://iojs.sleap.ai/usage.md, https://iojs.sleap.ai/api.md
- Can use a local sibling checkout at `../sleap-io.js` (Vite auto-detects). CI clones it automatically.

## Commands
```
npm run dev          # Browser dev server (port 5173)
npm run build        # Type check + production build
npm run lint         # ESLint
npm test -- --run    # Unit tests (Vitest, one-shot)
npm run test:e2e     # E2E tests (Playwright)
npm run tauri:dev    # Desktop dev mode
npm run tauri:build  # Desktop build
```

## Tests
- Unit tests: `tests/unit/`
- E2E tests: `tests/e2e/`
- Fixtures: `tests/fixtures/` (SLP files)

# Deployment
- On merge to `main`:
  - Deployed to: `https://app.sleap.ai/dev/`
- On GitHub Release:
  - Deployed to: `https://app.sleap.ai`
  - Tauri installer is built and attached to the release.
